# Vehiculo remoto usando MQTT
---

Implementación de un robot móvil de 2 GDL usando esp32 y protocolo MQTT para el control remoto del vehiculo.
Interfaz implementada en Node-Red. La guia de instalación y más detalles del robot pueden encontrarse en el `GETTING_STARTED.md`
